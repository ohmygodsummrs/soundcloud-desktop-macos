## What this is
SCDesktop: a native macOS SoundCloud client. Swift 5.10 package, SwiftUI + some AppKit
(`NSViewRepresentable`) views, AVPlayer for audio. No third-party dependencies.
Talks to SoundCloud's **private** web API (`api-v2.soundcloud.com`), authenticated with the
user's `oauth_token` cookie copied from soundcloud.com.

## Layout
- `Sources/SCDesktop/` — the whole app (single executable target, ~5k lines).
- `Scripts/make-app.sh` — release build → `build/SCDesktop.app` (ad-hoc signed, icon generated by `Scripts/make-icon.swift`).
- `.build/`, `build/` — build output (gitignored).

## Build / run
```bash
swift run SCDesktop                 # debug
SC_DEBUG=1 swift run SCDesktop      # logs every request/response to stderr (debugLog)
Scripts/make-app.sh                 # release .app; needs Xcode with macOS 26 SDK for Liquid Glass
```
Min target macOS 14. Liquid Glass (`NSGlassEffectView`) is used only when available (macOS 26), else `NSVisualEffectView`.

## Conventions (match these)
- `@MainActor @Observable final class` for state (`AppModel`, `Player`). Views read `AppModel` from the environment.
- Navigation: `AppModel.sidebar` (top-level `SidebarItem`) + `AppModel.stack: [Route]` (push/back). New detail page → add a `Route` case and handle it in `RouteScreen` (`Views/DetailScreens.swift`).
- Mutating API calls go through `AppModel.run("label") { ... }` which shows errors as a toast.
- Optimistic UI: like/repost/follow update the local `Set`s first (`likedTracks`, `following`, …).
- Paginated lists: use `PagedList` (`Views/Components.swift`) with an api-v2 path; it follows `next_href`.
- Models are `Decodable` with `convertFromSnakeCase`; use `Lossy<T>` for arrays where single items may fail to decode.
- **All UI strings** go through `L("English text")`; add the Russian translation to the `russian` dict in `Strings.swift`. Plurals: `plural(...)`.
- Colors only from the current `Palette` (`Theme.swift`), never hard-coded.
- Bool prefs: `Setting.bool(key, default:)` / `Setting.set`. Other prefs: plain `UserDefaults`.
- Comments explain *why*, one line, sparse. Small diffs. No new abstractions without need.

## Gotchas
- `client_id` is scraped from soundcloud.com JS bundles and cached in UserDefaults (`scClientID`). On 401/403 the client re-scrapes once and retries. If SoundCloud changes their bundle format, `SCClient.refreshClientID` regex breaks first.
- Token is stored in `~/Library/Application Support/SCDesktop/token` (0600), **not** the keychain (keychain prompted on every ad-hoc rebuild). Old keychain item is migrated and deleted.
- GET responses cached 5 min in memory + disk (`~/Library/Caches/SCDesktop/api`); stale copy served offline. Any non-GET invalidates the cache. `/media/` (signed stream URLs) never cached.
- Some Go+ tracks are DRM/encrypted → AVPlayer can't play them; `Player` filters/skips.
- Solid themes disable the glass layer and make windows opaque — transparent windows made touchpad scrolling stutter. Keep that.
- `Player.position/duration` are `@ObservationIgnored` on purpose (avoid re-rendering the whole UI every tick); `SeekBarView` polls them.
